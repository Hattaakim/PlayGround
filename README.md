# Kota Kita

**Kota Kita** is a browser-based Indonesian city-building game. Plan roads and zones, provide utilities and public services, balance the city budget, and grow your town into a metropolis.

## Play

Serve the files from this folder with any static web server, then open its address in a browser. For example, with Python installed:

```bash
python3 -m http.server 3000
```

Open <http://localhost:3000>. No build step or external packages are required.

## How to play

1. Start a new city and choose its name (or continue a saved city).
2. Build roads to connect future developments; buildings need road access.
3. Zone residential, commercial, and industrial land alongside roads.
4. Provide electricity and water so residents can move in, and add services and parks to improve city life.
5. Manage taxes and policies, respond to city events, complete missions, and work toward a population of 1,000.

### Controls

- **Desktop:** choose a category and building from the side panels, then click a map tile to build. Drag the map to pan and use the mouse wheel to zoom.
- **Touchscreen:** choose a category and building, then tap a tile. Drag to pan and pinch to zoom.
- Use the in-game help button for a guided introduction. The toolbar also includes save, sound, and city-statistics controls.

Cities are saved in the browser's local storage. Use the in-game save button to save manually; the game also saves automatically as you play.
